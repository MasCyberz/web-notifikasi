## Tentang Proyek Ini

Proyek ini adalah aplikasi web yang dirancang untuk mempermudah pengelolaan dan pengingat perpanjangan dokumen kendaraan, seperti STNK dan KIR. Dengan antarmuka yang sederhana dan intuitif, pengguna dapat dengan mudah memantau tanggal kedaluwarsa dan mendapatkan notifikasi tepat waktu untuk perpanjangan.

### Fitur Utama

-   **Notifikasi Perpanjangan**: Pengguna akan mendapatkan pengingat sebelum tanggal kedaluwarsa dokumen kendaraan.
-   **Pengelolaan Data Kendaraan**: Menyimpan dan mengelola informasi mengenai kendaraan yang dimiliki.
-   **Riwayat Perpanjangan**: Melihat riwayat perpanjangan kendaraan sebelumnya.
-   **Antarmuka Responsif**: Dapat diakses dengan baik di berbagai perangkat, baik desktop maupun mobile.

## Tentang Pengembang & Sekolah

Proyek ini dikembangkan oleh siswa jurusan **Rekayasa Perangkat Lunak** dari [SMK Negeri 12 Jakarta](https://www.instagram.com/smkn12_jkt/) sebagai bagian dari tugas praktek kerja lapangan (PKL). Melalui proyek ini, para siswa mengaplikasikan keterampilan pemrograman web untuk menciptakan solusi pengingat perpanjangan dokumen kendaraan.
